✨ 少羽出品必定nb WISE 每日任务

可藝中學 WISE 英語單詞任務一鍵工具：自動做當天任務 / 補做往日。
把下面的書籤代碼複製到瀏覽器書籤就能用。
⚠️ 平板/手機 Safari 安裝三步：
① Safari 打開任意網頁 → 分享 → 加入書籤，名稱「WISE任務」
② 書籤 → 長按「WISE任務」→ 編輯 → 網址欄徹底清空
③ 回本頁點「一鍵複製」→ 粘貼進網址欄 → 完成
💻 電腦用：瀏覽器按 Ctrl+Shift+O 打開書籤管理器 → 新增書籤，
名稱「WISE任務」，網址欄粘貼剛才複製的代碼即可。
自動複製失敗：請長按上方代碼框 → 全選 → 拷貝
📖 使用說明
  • 每天用法：登入 qms.hongai.edu.hk → 點書籤「WISE任務」
  • 右上角玻璃面板：金幣 / 完成天數 / 準確率統計
  • 日期列表：紅色 ✗ = 還沒練的日子，點選即可補做
  • 做題時逐詞選「✓ 答對 / ✗ 答錯」，全程走網頁真實界面
  • 再次點書籤 = 關閉面板
  • 🔒 本代碼不含任何賬號密碼，用前請先自己登入學校網站
